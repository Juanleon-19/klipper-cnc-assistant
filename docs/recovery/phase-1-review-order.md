# Orden de revisión de la Fase 1

Para revisar una diferencia grande sin mezclar responsabilidades:

1. Auditoría y procedencia: `docs/recovery/current-project-audit.md`.
2. Reglas y plan: `AGENTS.md`, `PLAN.md`, `README.md`.
3. Arquitectura: `docs/architecture.md`.
4. Configuración y despliegue: `.gitignore`, `deploy/`, `docs/deployment.md`.
5. Reorganización backend: `application/` frente a `execution/`.
6. Reorganización frontend: `components/` frente a `features/`.
7. Funciones recuperadas: Referencias, mapa, ejecución y persistencia.
8. Pruebas y evidencias físicas documentadas.

No revisar los 80+ commits como una sola masa. La decisión de merge debe tomarse después de cerrar cada grupo.
